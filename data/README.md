# Data

- `steam_reviews_sample.csv` - first 1,000 rows, committed for quick local testing.
- `steam_reviews.csv` - full 20,000-row dataset, gitignored. Fetch with:

```bash
curl -sL -o data/steam_reviews.csv "https://raw.githubusercontent.com/mrafifrbbn/steam-reviews/main/data/steam_reviews.csv"
```

Original source: a curated subset of the Steam Reviews Dataset from Kaggle
(provided by user Luthfi Mahendra), re-hosted at
[mrafifrbbn/steam-reviews](https://github.com/mrafifrbbn/steam-reviews).
